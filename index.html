The Archive System

Built for expansion.

The archive is being structured so the public page does not need to be manually redesigned every time a new song is created.

Future versions will load the music catalog from a separate track database and automatically generate the archive.

This will allow the NBS Wrestlin Music Archive to scale from a handful of tracks to 100+ songs while keeping the public interface consistent.
